# Data (not committed)

1. Download the Kaggle dataset **"Lending Club loan data"** :
   https://www.kaggle.com/datasets/wendykan/lending-club-loan-data (file `loan.csv` inside `archive.zip`, ~1.19 GB unzipped)
2. Put `loan.csv` in this folder (unzip it first).

The first run caches a cleaned extract in `data/interim/` so later runs are fast.
